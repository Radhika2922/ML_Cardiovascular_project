# CardioPredict – Cardiovascular Disease Prediction System

CardioPredict is a professional full-stack medical-technology web application designed to predict cardiovascular disease risk using supervised machine-learning classification models.

The system features a **React.js + Vite** frontend rendered in a clean white/light medical-tech interface and a **Python FastAPI** REST backend that loads a pre-trained **AdaBoost Classifier** model via **Joblib**.

---

## 🚀 Quick Start Guide

### 1. Backend Setup (FastAPI)

```bash
cd backend
pip install -r requirements.txt
python main.py
```

- **API Base URL**: `http://localhost:8000`
- **Interactive Swagger Documentation**: `http://localhost:8000/docs`
- **Health Check**: `http://localhost:8000/health`

### 2. Frontend Setup (React.js + Vite)

```bash
cd frontend
npm install
npm run dev
```

- **Frontend App URL**: `http://localhost:5173`

## 📡 REST API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | Verifies API service & ML model status |
| `POST` | `/predict` | Evaluates patient metrics and returns risk prediction |
| `GET` | `/model-info` | Returns active model metadata and feature list |
| `GET` | `/dataset-summary` | Returns EDA summary statistics for 62.5k dataset |
| `GET` | `/model-performance` | Returns benchmark metrics across 8 algorithms |

### Example `/predict` Request

```json
{
  "age": 45,
  "gender": 1,
  "height": 170,
  "weight": 70,
  "ap_hi": 120,
  "ap_lo": 80,
  "cholesterol": 1,
  "gluc": 1,
  "smoke": 0,
  "alco": 0,
  "active": 1
}
```

### Example Response

```json
{
  "success": true,
  "prediction": 0,
  "risk_label": "Lower Risk",
  "probability": 28.5,
  "bmi": 24.2,
  "risk_factors": ["Physiological parameters fall within standard baseline reference ranges."],
  "message": "The model predicts a lower cardiovascular disease risk.",
  "disclaimer": "For educational purposes only. This prediction is generated by a machine-learning model and is not a medical diagnosis."
}
```

## 🧠 Machine Learning Performance Summary

The system evaluates 8 classification algorithms trained on 62,500 patient records:

| Model | Test Accuracy | Precision | Recall | F1 Score | Cross-Validation |
|---|---|---|---|---|---|
| **AdaBoost (Active)** | **72.61%** | **73.05%** | **71.20%** | **72.11%** | **72.82% ± 0.34%** |
| Random Forest | 71.64% | 72.10% | 70.40% | 71.24% | 72.40% ± 0.39% |
| Tuned Decision Tree | 72.18% | 72.26% | 70.04% | 71.13% | 72.75% ± 0.38% |
| Logistic Regression | 72.12% | 72.04% | 70.52% | 71.27% | 72.28% ± 0.35% |

## 🌐 Cloud Deployment Architecture

- **Frontend (React)**: Deployed independently on **Vercel** or **Netlify**. Set environment variable `VITE_API_URL=https://your-fastapi-backend.onrender.com`.
- **Backend (FastAPI)**: Deployed on **Render** or **Railway**. Configured with entrypoint command `python main.py` or Uvicorn startup command: `uvicorn main:app --host 0.0.0.0 --port $PORT`.
